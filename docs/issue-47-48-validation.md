# Issues 47 and 48: investigation and TLS key lifecycle

Comparison entered from an analyzed capture retains its original File, applied key-log File, route including shared filters, view-state map, drawer context, content scroll and table scroll in tab memory. Its analysis worker terminates before comparison opens a worker. Back closes the comparison worker synchronously and reanalyzes the original file with its own keys. Restoration displays progress, supports retry on failure, can return to the prior key configuration, and offers Return to start. Comparison entered without an analyzed workspace returns to the start screen. Replacement and Close clear the capture snapshot and keys.

The compact TLS keys disclosure distinguishes staged files (results unchanged) from the active key log. Apply keys to current capture reanalyzes the retained File; Remove active keys reanalyzes without keys. The active status reports actual decrypted session counts, including no matching decrypted sessions. Failed or cancelled key updates never mark the requested keys active; returning to previous analysis reinstates the previously applied keys. Keys never enter persistence, hashes or exports and are not reused on replacement.

Dedicated browser coverage: `e2e/workspace-lifecycle.spec.ts` covers repeated seeded Back without reopening, route/shared-host filter, table search and selected conversation restoration, packet-table offsets beyond the first 500-row page restored after asynchronous matched-count loading, failed restoration retry and start fallback, Back during analysis, stale comparison responses and an instrumented maximum of one living worker. Real TLS 1.3 HTTP/2 fixtures cover staging, apply, retention through comparison, removal, unmatched keys and replacement isolation; an instrumented worker exercises failed and cancelled key updates returning to the previous active keys. The TLS disclosure supports Escape, visible Close TLS keys and outside-pointer dismissal. Existing TLS browser tests and worker engine tests remain applicable.
